Boundary

Art Direction

The player is operating illegal analog communications equipment inside hostile digital territory.

Signal 9 should look like resistance infrastructure — field radios, rack gear, avionics panels, CRT monitors, signal analyzers, and improvised archive machines. Full document: Art Direction.

Theme Architecture

Plantasonic DS → --s9-* bridge → presets → components → app layout. Requires .s9-themed on <html>.

Visual Sources

  • Shortwave radio consoles, pirate radio stations, military avionics
  • Oscilloscopes, spectrum analyzers, packet analyzers, CRT terminals
  • Tape decks, vinyl equipment, signal intelligence workstations
  • Archive rooms, number stations, emergency broadcast systems

Surface, Shape & Color

  • Matte black casings, CRT phosphor, printed labels, rack-unit proportions
  • Rectangular modules, terminal cells, meter bays, diagnostic slots
  • Color as signal — carrier identity, amber warnings, red danger, gray offline
  • Texture tied to source: RF static, scanlines, tape noise, signal ghosting

Identity Mark

  • Figlet slant ASCII logo from signal9LogoArt.ts
  • Static: .s9-ascii-logo__output--static on Tempo Scanner header
  • Animated: ASCII Visual Engine on intro screens (signal-9-live-eq)

Presets

  • broadcast — violet carrier (default)
  • interference — cold cyan static corruption
  • jammer — fuchsia pulse interference
  • uplink — emerald data stream
  • blackout — collapsed void, heavy threshold

Avoid

  • SaaS dashboards, mobile app UI kits, streaming service interfaces
  • Frosted glass app shells, friendly rounded cards, decorative cyberpunk neon
  • Hero marketing curves, generic analytics modules, lifestyle music apps

Approval Checklist

  • Does it feel like equipment?
  • Is every effect tied to signal, memory, hardware, or surveillance?
  • Does it avoid modern SaaS and consumer app patterns?
  • Does it make music and memory feel culturally important?
  • Can it be implemented with existing Signal 9 theme ownership?

Rules

UI Principles

Foundational rule: Every UI element must have an operational reason to exist — monitor signal, control transmission, decode memory, expose mission state, warn about interference.

Equipment, Not Software

Treat every screen as an instrument panel. Use panel labels, state indicators, telemetry strips, signal meters, and hardware-like grouping. Avoid generic cards, marketing sections, and decorative stats.

Interface vs Visual Content

Panel structure remains inspectable DOM/CSS UI. Live visual content inside equipment bays may be ASCII, canvas, or generated instrumentation — do not collapse into one giant ASCII canvas.

Feedback

GSAP Motion States

Motion is a lightweight state feedback layer in js/s9-motion.js, not a separate design system. GSAP loads via CDN ESM — no build step.

  • Startup reveal — staggered fade on [data-s9-reveal] sections
  • ASCII logo flicker — stepped brightness boot
  • Tap pulse — BPM readout scale, EQ/signal lock/rhythm grid opacity
  • Signal lock meter update — bar opacity flash on value change
  • Mic scan pulse — subtle repeating opacity on .s9-ascii-eq
  • Key scan pending — gentle pulse while decoding
  • Button press feedback — scale on pointer down/up

Rules

  • prefers-reduced-motion disables all GSAP tweens — functional state changes remain
  • Infinite tweens (mic scan, key pending) are killed when scan stops or lock resolves
  • Motion must not break readability or cause layout shift
  • Preferred easing: power2.out, power3.out, steps(8)

≤ 980px

≤ 680px

ASCII logo scales down via clamp without forcing page scroll. Critical readouts remain legible at all breakpoints.

Reliability

Accessibility

  • High contrast text on dark equipment surfaces
  • prefers-reduced-motion disables decorative animations, GSAP tweens, and style guide motion demos
  • Panel states use text labels — not color alone (data-panel-state + readable copy)
  • Keyboard-operable deck controls with :focus-visible ring on buttons
  • CRT atmosphere effects are non-interactive overlays — critical readouts remain legible
