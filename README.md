# BPM

A minimal tap-tempo instrument for quickly finding beats per minute.

**[Launch the live prototype](https://bpm-ten.vercel.app/)**

## Status

Active prototype. The core tap-tempo interaction is live.

## What it demonstrates

- A focused single-purpose interaction
- Fast visual feedback
- Responsive product prototyping with React
- A compact Vinext/Vite application architecture

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run lint
npm test
```

## Stack

React · TypeScript · Vinext · Vite · GSAP
